# Equipo técnico por nivel

Inventario orientativo. Las marcas y modelos son ejemplos; se cotiza cuando definamos presupuesto
y lugar de grabación (ver `DECISIONES.md`). Precios pendientes de cotizar en el mercado local.

## Nivel 1 — Básico / remoto (1–2 personas)

| Categoría | Ejemplo | Cant. |
|---|---|---|
| Micrófono dinámico USB/XLR | Shure MV7+, Samson Q2U, Rode PodMic USB | 1 por persona |
| Audífonos cerrados | Audio-Technica ATH-M40x / Sony MDR-7506 | 1 por persona |
| Cámara | Webcam 4K o celular con trípode | 1 por persona |
| Luz | Panel LED o aro con difusor | 1 por persona |
| Plataforma remota | Riverside, Zencastr, SquadCast | Suscripción |
| Edición | Descript / Audacity / CapCut / DaVinci Resolve (gratis) | — |
| Masterización | Auphonic | Suscripción o créditos |

## Nivel 2 — Intermedio (estudio sencillo, 2–3 voces, 2–3 cámaras)

| Categoría | Ejemplo | Cant. |
|---|---|---|
| Micrófono dinámico XLR | Shure SM7B / MV7X, Rode PodMic, Electro-Voice RE20 | 1 por persona + 1 de repuesto |
| Brazo articulado | Rode PSA1+ o similar | 1 por micro |
| Interfaz / mezcladora-grabadora | Rodecaster Pro II / Duo, Zoom PodTrak P8, Tascam Mixcast | 1 |
| Grabadora de respaldo | Zoom H6essential o grabación en tarjeta de la mezcladora | 1 |
| Audífonos + amplificador de audífonos | ATH-M50x + Behringer HA400 | 1 por persona |
| Cámaras | Mirrorless con salida limpia y sin límite de 30 min (Sony ZV-E10 II, Panasonic Lumix G9 II, etc.) | 2–3 |
| Lentes | Zoom estándar + uno luminoso | Según cámaras |
| Luces | 2–3 paneles LED bicolor con softbox (clave + relleno + contra) | 3–4 |
| Tratamiento acústico | Paneles absorbentes, alfombra, cortinas gruesas | Según sala |
| Almacenamiento | SSD externos 2–4 TB ×2 + nube | — |
| Cables, tarjetas, baterías | XLR, SD V60/V90, baterías extra, regletas | — |

## Nivel 3 — Estudio profesional / multicámara en vivo

Todo lo anterior, más:

| Categoría | Ejemplo |
|---|---|
| Switcher con grabación ISO | Blackmagic ATEM Mini Extreme ISO / ATEM Television Studio |
| Cámaras de estudio / PTZ | Blackmagic Studio Camera, PTZ 4K |
| Timecode | Tentacle Sync / Deity TC-1 |
| Grabación de pistas | Grabadora multipista 32-bit float (Zoom F6/F8n Pro, Sound Devices MixPre) |
| Monitores de referencia | Monitores de estudio + tratamiento de sala de edición |
| Teleprompter / monitor de retorno | Para lecturas y gráficos |
| Almacenamiento compartido | NAS con RAID + respaldo en nube |
