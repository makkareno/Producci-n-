# Roles y matriz RACI

## Roles

| Código | Rol | Responsabilidad principal |
|---|---|---|
| PE | Productor/a ejecutivo/a | Visión, decisiones editoriales finales, presupuesto, alianzas y patrocinios. |
| PR | Productor/a | Hace que todo pase: calendario, invitados, logística, QC, publicación. Dueño/a de esta matriz. |
| HO | Host / conductor(a) | Conducción, preparación del tema, aprobación del corte. |
| IN | Investigación / guion | Dossier, escaleta, verificación de datos, notas del episodio. |
| SO | Sonido | Microfonía, niveles, grabación de audio, respaldo de audio. |
| CA | Cámara / realización | Cámaras, luces, encuadres, (switcheo en vivo si aplica). |
| EA | Edición de audio | Corte, limpieza, mezcla, máster, capítulos. |
| EV | Edición de video | Multicámara, color, gráficos, subtítulos, clips. |
| DI | Diseño | Identidad, portadas, miniaturas, gráficos en pantalla. |
| CM | Redes / community | Calendario de redes, clips, comunidad, kit del invitado. |
| AN | Análisis | Métricas, tablero, reportes a patrocinadores. |

## RACI por fase

**R** = lo hace · **A** = aprueba / rinde cuentas · **C** = se consulta · **I** = se informa

| Fase | PE | PR | HO | IN | SO | CA | EA | EV | DI | CM | AN |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 0 Desarrollo | A | R | R | R | C | C | I | I | R | C | I |
| 1 Preproducción | A | R | C | R | C | C | I | I | C | I | I |
| 2 Producción | I | A | R | C | R | R | I | I | I | C | I |
| 3 Postproducción | A | C | C | I | C | I | R | R | C | C | I |
| 4 Distribución | I | A/R | I | C | I | I | C | C | R | C | I |
| 5 Promoción | C | A | C | I | I | I | I | R | R | R | I |
| 6 Medición | A | R | C | I | I | I | I | I | I | C | R |

## Cómo se reparten los roles según el tamaño del equipo

| Equipo | Reparto sugerido |
|---|---|
| **1 persona** | Todo. Reducir: solo audio o 1–2 cámaras fijas, edición ligera, apoyarse en herramientas (Riverside, Descript, Auphonic, clips automáticos). |
| **2 personas** | A: Host + PE + IN. B: PR + SO/CA + EA/EV + CM. |
| **3 personas** | A: Host + PE. B: PR + IN + CM + AN. C: SO/CA + EA/EV + DI. |
| **4–7 personas** | Host · PE · PR (+IN) · Técnico (SO+CA) · Editor (EA+EV) · Diseño + Redes (DI+CM) · AN compartido. |
| **8+** | Un rol por persona; considerar coordinador/a de postproducción. |

Regla: el rol de **PR** (que alguien sea dueño del proceso y del calendario) nunca se queda sin asignar.
