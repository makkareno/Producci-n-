# Fase 1 — Preproducción (por episodio)

**Cuándo:** de G − 21 a G − 1.
**Entradas:** biblia del show, calendario editorial, lista de invitados.
**Salidas:** ficha de episodio, dossier de investigación, escaleta, brief al invitado, cesión firmada, hoja de llamado.

> Regla práctica: una buena preproducción ahorra el doble de horas en postproducción.
> Lo que no se resuelve aquí, se termina editando.

## Flujo

```
Tema propuesto → Aprobación (PE) → Búsqueda de invitado → Invitación → Confirmación
      → Cesión firmada → Investigación → Escaleta → Brief al invitado
      → Prueba técnica → Hoja de llamado → GRABACIÓN
```

## Checklist

### Editorial
- [ ] Ficha de episodio abierta ([plantilla](../plantillas/ficha-de-episodio.md)): tema, ángulo, objetivo, qué se lleva el oyente
- [ ] Tema aprobado por PE
- [ ] Investigación: biografía del invitado, entrevistas previas (para no repetir preguntas), datos con fuente
- [ ] Escaleta con tiempos ([plantilla](../plantillas/escaleta.md)): apertura/gancho, bloques, preguntas clave, cierre y llamado a la acción
- [ ] 3 preguntas "imprescindibles" marcadas (si solo se graban 20 minutos, deben salir)
- [ ] Ideas de clips anticipadas: qué momentos esperamos que funcionen en vertical

### Invitado
- [ ] Invitación enviada ([plantilla](../plantillas/invitacion-invitado.md))
- [ ] Fecha, hora (con zona horaria) y modalidad confirmadas por escrito
- [ ] Cesión de derechos firmada ([ver legal](../anexos/legal.md))
- [ ] Brief enviado: de qué va el show, temas a tocar, duración, cómo llegar o cómo conectarse, qué vestir (si hay video: evitar rayas finas, verde si hay croma, logos)
- [ ] Datos para créditos: nombre como quiere aparecer, cargo, @redes, enlace a promover, foto
- [ ] Temas que el invitado **no** quiere tocar

### Logística y técnica
- [ ] Estudio / espacio reservado
- [ ] Equipo reservado y revisado (baterías, tarjetas formateadas, cables)
- [ ] Personal confirmado
- [ ] Si es remoto: prueba técnica con el invitado (audífonos, micrófono, cámara, luz, conexión cableada)
- [ ] Hoja de llamado enviada ([plantilla](../plantillas/hoja-de-llamado.md))
- [ ] Gráficos/materiales en pantalla preparados

## Kit mínimo para invitado remoto

Enviar con el brief:
1. Usar **audífonos** (evita eco).
2. Micrófono USB o de diadema; si no hay, audífonos con micrófono, no el de la laptop.
3. Cuarto pequeño, con cosas blandas (cortinas, sillón, ropa); evitar cuartos vacíos.
4. Luz de frente (ventana o lámpara delante, nunca detrás).
5. Cámara a la altura de los ojos.
6. Internet por cable si es posible; cerrar apps y notificaciones.
7. Navegador Chrome actualizado (para plataformas tipo Riverside/Zencastr).
